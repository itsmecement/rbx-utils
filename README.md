# rbx-utils

A collection of reusable Luau utilities and modules for Roblox Studio development

## Modules

| Module | Description |
|---|---|
| [ModuleRelocator](Modules/ModuleRelocator/) | An advanced auto architecturing tool for server code preservation. |
| [Loader](Modules/Loader/) | A reusable module loader. |
| [State](Modules/State/) | A simple, reusable state class. |

## Installation

Download the desired `.rbxm` file and import it into Roblox Studio.
